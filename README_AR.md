# مسابقة المحبة Live

موقع تفاعلي شبيه بكاهوت للدرس الثالث، مع غرفة مباشرة وPIN ولوحة ترتيب وتقرير نتائج.

## الحماية من إعادة المحاولة
كل مخدوم يحصل على كود شخصي سري، مثل LOVE-001. قاعدة البيانات تمنع استخدام الكود نفسه مرتين داخل الغرفة، حتى لو غيّر الاسم أو الجهاز.

## التشغيل المحلي
1. ثبّت Node.js 20 أو أحدث.
2. افتح Terminal داخل المجلد.
3. شغّل: `npm install`
4. في Windows PowerShell:
   `$env:ADMIN_PASSWORD="كلمة-مرور-قوية"; $env:SESSION_SECRET="نص-سري-طويل"; npm start`
5. افتح `http://localhost:3000`.

## النشر كرابط عام
يمكن رفع المشروع على Railway أو Render. أضف متغيري البيئة:
- `ADMIN_PASSWORD`
- `SESSION_SECRET`

للاستخدام الدائم على Railway، اربط Volume واجعل `DB_PATH=/data/quiz.db` حتى لا تضيع النتائج عند إعادة التشغيل.

## الاستخدام
- الخادم يضغط "دخول الخادم" وينشئ غرفة تلقائيًا.
- يرسل الرابط العام وPIN للمخدومين.
- يرسل لكل مخدوم كوده الشخصي بصورة منفصلة.
- بعد دخول الجميع يبدأ المسابقة.
- في النهاية ينزّل تقرير CSV بالأسماء والأكواد والدرجات.

## ملاحظة أمان
غيّر كلمة المرور الافتراضية قبل التشغيل العام. لا تشارك أكواد المخدومين في الجروب؛ أرسل كل كود لصاحبه فقط.
